name: agents-md-slim
description: AGENTS.mdなどエージェント向け指示ファイルを監査し、冗長・自明・古い記述を優先度順に洗い出してスリム化案を出すスキル。
---

指示・コンテキストは少ないほどモデルの性能が上がる。残すのは「モデルの既定の振る舞いと異なり、コードを読んでもわからない、このプロジェクト固有のルール」だけ。

# 手順

1. 対象ファイルを読む。
2. 記述を鵜呑みにせず、実物と突き合わせる。
   - package.json の scripts / dependencies、lint・tsconfig などの設定ファイル
   - ディレクトリ構成、参照されているファイル・コマンドが実在するか
3. 各記述を以下の基準で分類し、削減効果の大きい順に並べる。優先度（高・中・低）ごとに、該当箇所と根拠を箇条書きで示す。
4. スリム化案を提示する。ファイルの書き換えはユーザーの承認を得てから行う。

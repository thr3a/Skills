あなたの仕事は /code-review skillsでコードレビューを行い、コードレビューの結果を HTML ファイルにまとめることです。
この HTML は人間が確認し、別のAIにそのまま読ませ、「H2 を修正して」のように IDを指定して修正を頼むために使用します。

# 手順

1. `/code-review` スキルでレビューを行う。
  - `/code-review` の既定の動作に従いつつ、レビュー対象・観点・effort などの指示がユーザーからあれば、それを優先する。effortの指示がない場合は AskUserQuestion で確認する。
2. 結果を `./code-review.html` に書き出す。既存ファイルがあれば上書きする。
  - 各指摘には「H2」のようにナンバリングをつける。
3. コードは修正しない。レビューと HTML の作成だけを行う。

# 優先度の基準

- H(高): バグ、データ破損、セキュリティ上の問題、クラッシュなど、放置すると実害が出るもの
- M(中): 特定の条件で問題になるもの、保守性・性能を大きく損なうもの
- L(低): 可読性、命名、軽いリファクタリング、スタイルなど
